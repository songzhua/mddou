# mddou
小豆阅读器（mddou） — 一款本地 Markdown 阅读与编辑工具，离线、免费、轻量。

核心功能：

📝 Markdown 渲染：标题、列表、代码块、表格、引用、链接等标准语法，所见即所得

🎨 多主题：支持亮色/暗色/纯黑护眼主题切换

📊 Mermaid 流程图：直接渲染 ```mermaid 代码块，看图表不用装插件

➗ 数学公式：支持 LaTeX 行内 $...$ 和块级 $$...$$ 公式渲染

🖼️ 图片：支持粘贴截图/拖入图片，自动保存到文档旁的 images 目录

🗂️ 多标签页：同时打开多个文档，标签页切换

💾 导出：一键导出 PDF 或 Word 文档，图表和公式完整保留

🔗 文件关联：安装后双击 .md 文件直接用阅读器打开
